# Новая версия

Как собрать версию Metobe и что написать людям о ней. Как обновление ставится на сервер — [DECISIONS.md](DECISIONS.md), D35.

## Порядок

1. **Каждое изменение — свой PR.** Ветка не копит несколько функций: release-please собирает CHANGELOG из заголовков коммитов, и одна ветка на пять изменений даёт в нём одну строку.
2. **Заголовок PR — conventional commit на английском**, глазами пользователя: `feat: share a chat with the team by link`, а не `feat: chat visibility column`. Это строка CHANGELOG.
   - `feat` до 1.0 поднимает минорную версию (0.5 → 0.6), `fix` — патч (0.6.0 → 0.6.1).
   - Изменения только для разработчиков — `chore`, `ci`, `docs`, `refactor`: в CHANGELOG они не попадают.
3. **Миграции.**
   - Нумеруются подряд и применяются обновлятелем.
   - Если миграция не откатывается сама, обновлятель возвращает базу из бэкапа, сделанного перед обновлением. Значит, миграция не должна трогать ничего вне базы.
4. **Перед релизом:**
   - lint, типы и тесты зелёные на `main`;
   - миграции применены на dev;
   - «Что нового» готово на всех языках (ниже).
5. **Release PR** открывает release-please. Сливает его только человек.

## «Что нового»

После обновления каждый пользователь один раз видит окно «Что нового». Это не CHANGELOG: CHANGELOG пишется для разработчиков, а окно — для тех, кто работает в чате.

Окно — тур по одному изменению на страницу: на обложке созвездие из крупных изменений, на каждой странице живое демо, которое показывает курсор, в конце «И ещё» на том же небе. Прототип — `/dev/prototypes/whats-new`.

### Как добавить версию

1. Запись в `RELEASE_NOTES` (`packages/core/src/whats-new-notes.ts`), новой версией сверху: дата, `featured` (крупные), `more` («И ещё»), `admin`.
2. Тексты — `whatsNew.changes.<id>` в `ru.json` и `en.json`: у крупного `short`, `title`, `text`, у остальных `title`, `text`.
3. У каждого крупного — демо в `apps/web/components/whats-new/demos.tsx` и, если его стоит показать курсором, сценарий в `autoplay.tsx`. Изменение без демо в тур не попадёт.
4. Проверить: `METOBE_APP_VERSION=<версия>` у дева и `whats_new_seen` прошлой версии у своего пользователя — окно откроется само.

### Что попадает

- **Крупных изменений — не больше шести.** Каждое получает свою страницу и звезду на обложке. Седьмую страницу не долистают.
- **Остальное — в «И ещё»**, по строке на изменение.
- **Исправления, которые человек не заметит, не пишем вовсе.**
- **Изменения для админа** — отдельным блоком «Для администратора». Его видит только админ.
- **Только то, что точно вошло в эту версию.** Каждое утверждение сверяем с кодом. Если неясно, в какой версии что-то появилось, — не пишем.

### Как писать

- **Что теперь можно, а не что сделано.**
  - «Чат можно отправить коллеге», а не «Добавлен шаринг чатов».
- **У крупного изменения четыре части:**
  - имя звезды — одно-два слова: «Поделиться»;
  - заголовок — что теперь можно, до 40 знаков;
  - текст — два предложения: что это и как этим пользоваться;
  - демо.
- **Тон.** На «вы», спокойно. Без «Мы рады представить», восклицаний и превосходных степеней.
- **Языки.** Тексты — в файлах переводов (`packages/i18n/messages`), на всех языках интерфейса: сейчас `ru` и `en`. В коде ни одной строки. Версия без перевода на какой-то язык не выпускается.

### Демо, а не скриншоты

- **На картинке — живые компоненты продукта** с выдуманными данными. Компоненты те же, что в чате: поменялись в продукте — поменялись и в окне. Перевод тоже тот же.
- **Скриншотов не делаем.** Их нужно переснимать под каждый язык и тему, и на них легко попадают чужие данные.
- **Примеры нейтральные, годятся для любой компании:** план рассылки, отчёт по продажам, письмо поставщику. Никаких данных конкретной установки — своих 1С-баз, клиентов, сумм, адресов.
- **Имя, адрес установки и время** берутся у того, кто смотрит: из сессии, `window.location` и его часового пояса.
- **Что ушло бы на сервер** (например, включение доступа к чату), демо делает понарошку, на странице.
- **Каждое демо проверяем:**
  - в светлой и тёмной теме;
  - на телефоне;
  - с клавиатуры;
  - с уменьшенным движением: курсора нет, демо просто стоит.

### Когда показывается

- Один раз на версию, после обновления.
- Тому, кто вошёл впервые, не показывается: ему всё новое.
- Флажок «Не показывать после обновлений» отключает окно для следующих версий.
- Перечитать можно из меню аккаунта.
- **В окне только последняя версия.** Если человек пропустил несколько, окно покажет самую новую, а все версии целиком — на странице «Что нового в Metobe» (`/whats-new`): кнопка «Все изменения по версиям» на последней странице окна. Страница живёт внутри Metobe, а не на внешнем сайте: у установки может не быть выхода в интернет, и страница показывает ровно то, что стоит у людей.
