Переменные: `MODELS`, `LANGS` (`en,ru`), `CONCURRENCY` (4), `MAX_RETRIES` (2), `ZDR` (по умолчанию включён). Подробности по каждому решению — `results/<модель>.<язык>.json` (в git не попадают).

## Что проверяем

Набор `cases.ts`: русские сообщения, сегодня — понедельник 9 ноября 2026. 69 вызовов, 274 решения на модель и язык формулировок:

- **Ступень записи** (36 сообщений): есть ли что запомнить; факт / событие / обязательство / правило (да/нет каждое); кто кому должен; точность даты (день / неделя / месяц / нет).
- **Какая карточка** (13): выбор из 7 карточек + «новый» + «непонятно» (два Андрея, фамилии, «закупщик поставщика», «наш перевозчик»).
- **Закрывает ли обязательство** (10 сообщений × 5 открытых): частичное выполнение и перенос срока — не закрывают.
- **Как новое относится к текущему факту** (10): заменяет / прошлое / исправление / дополнение.

- **Русский работает.** Язык формулировок вопросов почти ничего не меняет; данные в обоих случаях русские.
- **Уверенные ответы почти всегда верны.** У Jev 72 % решений с P ≥ 0,9 (или ≤ 0,1), среди них ошибок нет. Ошибки Jev — около 0,5: «Марина попросила подписать заявление до пятницы» — «запомнить?» 0,41; «Ольга прислала тарифы» — «непонятно» 0,42 при одной Ольге в карточках. Порог уверенности разводит «записать тихо» и «черновик».
- **Остальные ошибки Jev** — границы типов: «раз в месяц хочу проверять дебиторку» — факт (0,87), «Вектор подписал договор» — между другими (0,82), «декрет в декабре» — не факт. Лечится формулировками и тем, что решение «запомнить» — это «любой тип да», а не отдельный вопрос.
- **Цена.** Jev — ~800–1100 токенов на сообщение со всеми вопросами ступени: около $0,00004, тысяча сообщений — 4 цента.
- **Стабильность.** Из трёх прогонов Jev один шёл с полосами по 3–4 с и 6 сбоями из 69 (`Gateway request failed` через ~70 с), два других — без сбоев, p95 до 0,7 с. Запись в память фоновая, поэтому нужен повтор и отложенная очередь, а не ожидание.
- **ZDR.** Perplexity, Liquid и Laya не дают запрета хранения — для личной памяти не годятся, пока он не появится.

**Вывод для D39:** первая ступень и решения памяти (карточка, закрытие обязательства, отношение к факту) — на моделях решений через Gateway. Из моделей с ZDR — Jev (быстрее и стабильнее по p95), Microsoft Decision-1 и Mammoth-1 (немного точнее). Набор маленький: разница в 1–2 % — это 3–5 решений, поэтому выбор между ними — после набора больше и с настоящими сообщениями. Текст факта эти модели не пишут — вторая ступень не проверялась.

Модель получает сообщение, сегодня (пн 9.11.2026, Москва) и 8 известных карточек; возвращает новые сущности и записи (тип, текст, ссылки, кто кому должен, когда, срок, интервал) через `Output.object`. Проверка: нашлась ли запись нужного типа с нужными ссылками, совпали ли дата и точность.

Промпт v2 добавил три правила после первого прогона: «ждём ответа» — обязательство другой стороны; у обязательства `when` — когда дано, `due` — срок; у каждого упомянутого есть ссылка, даже без имени («поставщик упаковки»). В v1 эти три места проваливали все модели, включая Sonnet 5.

- **Обе пустые проверки** («посчитай», «сделай план») все модели прошли — ни одной записи.
- **Даты — главное различие.** Трудные места: «в прошлый вторник сказал, что через две недели» (17.11 от 3.11, не от сегодня), «позавчера сказал, что к 1 декабря» (когда дано ≠ срок), «через две недели» (23.11), «на днях». Alice AI и YandexGPT ставят будущие даты вместо прошедших («в среду встречался» → 11.11).
- **Текст.** У DeepSeek через Яндекс и Gemini Flash-Lite — короткие предложения с полными именами, без оценок и домыслов. DeepSeek раскрывает относительные даты в тексте («вчера (8 ноября)»), Gemini — не всегда («до пятницы»): в промпт — «в тексте даты абсолютные».
- **Один и тот же DeepSeek v4.1 Flash** через Яндекс — 100 / 100 %, через Gateway — 79 / 52 %. Причину не выяснял: другой провайдер за Gateway или другие настройки рассуждений.
- **Цена DeepSeek в Яндексе** в каталоге dev не заведена; по D37 вход — 0,3 ₽ за 1000 токенов, то есть ~0,4 ₽ за сообщение без выхода. Пишет запись только то, что пропустила первая ступень.

**Вывод:** вторая ступень на русском работает на недорогих моделях: DeepSeek v4.1 Flash через Яндекс (для тех, кто без Gateway) и Gemini 3.5 Flash-Lite через Gateway — на уровне Sonnet 5 при цене в 10 раз ниже. Набор маленький — 33 записи, 27 дат: выбирать по умолчанию после набора больше и на настоящих сообщениях.
